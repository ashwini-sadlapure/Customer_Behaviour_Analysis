# Cutomer Behaviour Analysis project

## Overview

This project demonstrates an end-to-end **Data Analytics workflow**, from loading and cleaning raw data to generating business insights through SQL and Power BI.

The project covers **Python-based data analysis, Exploratory Data Analysis (EDA), data cleaning, SQL querying, interactive dashboard development, reporting, and presentation creation**.

## Dataset

The project uses a structured dataset containing business/customer-related information.

The dataset was:

* Loaded and explored using Python
* Checked for missing and duplicate values
* Cleaned and prepared for analysis
* Stored in a relational database for SQL analysis
* Connected to Power BI for dashboard development

## Tools & Technologies

* **Python** – Data loading, cleaning and EDA
* **Pandas** – Data manipulation and analysis
* **Matplotlib / Seaborn** – Data visualization
* **PostgreSQL / MySQL / SQL Server** – SQL analysis and querying
* **Power BI** – Interactive dashboard and visualization
* **Gamma** – Project presentation (PPT)
* **Microsoft Excel / CSV** – Dataset handling

## Project Steps

### 1. Data Loading

Loaded the dataset into Python using Pandas and inspected its structure, columns, data types, and basic statistics.

### 2. Exploratory Data Analysis

Performed EDA to identify:

* Data distributions
* Important trends and patterns
* Missing values
* Duplicate records
* Outliers
* Relationships between variables

### 3. Data Cleaning

Prepared the dataset for analysis by:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Standardizing column values
* Handling inconsistent or invalid data
* Preparing clean data for database analysis

### 4. SQL Analysis

Loaded the cleaned dataset into **PostgreSQL / MySQL / SQL Server** and performed SQL analysis using:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* Aggregate functions
* `JOIN`
* Subqueries
* CTEs
* Window functions

SQL queries were used to answer important business questions and identify key insights from the data.

### 5. Power BI Dashboard

Created an interactive Power BI dashboard to present the analysis visually.

The dashboard includes:

* KPI cards
* Charts and graphs
* Category-wise analysis
* Trend analysis
* Filters and slicers
* Interactive visualizations

### 6. Report

Created a detailed project report covering:

* Business problem
* Dataset description
* Data cleaning
* EDA findings
* SQL analysis
* Dashboard insights
* Key conclusions
* Recommendations

### 7. Presentation

Created a professional project presentation using **Gamma**, summarizing the complete analytics workflow, key findings, dashboard, and business recommendations.

## How to Run

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
cd <project-folder>
```

### 2. Install Python Libraries

```bash
pip install pandas matplotlib seaborn jupyter
```

### 3. Run the Python Analysis

Open the Jupyter Notebook:

```bash
jupyter notebook
```

Run the notebook to perform data loading, cleaning, EDA, and visualization.

### 4. Run SQL Queries

Import the cleaned dataset into **PostgreSQL, MySQL, or SQL Server** and execute the SQL scripts available in the `sql/` folder.

### 5. Open the Power BI Dashboard

Open the `.pbix` file using **Microsoft Power BI Desktop**.
